Step-by-Step Guide

Installation Instructions

Detailed instructions to install and bypass macOS Gatekeeper or Windows SmartScreen warnings.

1

Download & Mount the .DMG

Open the downloaded Security.Guard-1.0.0-arm64.dmg (or Intel version) and drag Security Guard into your Applications folder.

2

Fix macOS Sequoia / Sonoma ("Damaged & Move to Bin" Warning)

In macOS Sequoia, Apple removed the general "Open Anyway" button in System Settings for quarantined internet downloads. When downloaded from Chrome or Safari, macOS attaches a quarantine flag and shows: "Security Guard is damaged and can't be opened. You should move it to the Bin." The application is completely safe and NOT damaged.

⚡
Method 1: 1-Line Terminal Fix (Works 100% on All Mac Versions)

Open Terminal, paste this command, and press Enter:

xattr -cr "/Applications/Security Guard.app"

This permanently removes the quarantine flag that Chrome attached, and the app will open immediately.

Method 2: Finder Right-Click (Control-Click)
  1. Open Finder → go to Applications.
  2. Hold down the Control (Ctrl) key and click (or right-click) on Security Guard.app.
  3. Click Open from the context menu → then click Open in the confirmation box.
3

Launch Application

Double-click Security Guard in Applications. The continuous background shield and host telemetry automatically initialize.

1

Download & Run Installer

Download Security.Guard.Setup.1.0.0.exe and double-click to start installation.

2

Bypass Windows SmartScreen ("Windows protected your PC")

Because this is an open-source community tool without an expensive corporate EV certificate, Microsoft Defender SmartScreen displays a warning.

🛡️
How to Continue Installation:
1. On the blue/red SmartScreen dialog, click "More info".
2. Click the "Run anyway" button at the bottom.

Or Right-click the .exe → Properties → check Unblock at bottom → click OK.
3

Complete Setup

Choose your install path, finish installation, and Security Guard will launch with desktop shortcuts created.

1

Make AppImage Executable

Download Security.Guard-1.0.0.AppImage, then open terminal and mark it executable:

chmod +x Security.Guard-1.0.0.AppImage && ./Security.Guard-1.0.0.AppImage
2

Or Install via .DEB (Ubuntu / Debian)

Install natively via dpkg:

sudo dpkg -i security-guard_1.0.0_amd64.deb
User Workflow

How to Use Security Guard

Simple 4-step workflow to safeguard your workstation and codebase.

STEP 01

Launch App & Auto-Shield

When you launch the app, the continuous background filesystem watcher (guard watch) and silent PC malware scan automatically activate.

STEP 02

Scan Local Disks

Navigate to the Local PC tab, view detected physical/logical drives, and click "Scan Disk" to audit for injected malware without scanning Git repos.

STEP 03

Audit GitHub Codebases

Connect via the GitHub tab to scan private/public repositories for BeaverTail droppers, poisoned dependencies, and unauthorized collaborators.

STEP 04

1-Click Trojan Deletion

Review your findings in the Reports tab. Click "🗑️ Delete Trojan (Move to Trash)" to eliminate compromised files immediately.
